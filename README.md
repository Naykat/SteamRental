# Playerok Steam Rental

Автовыдача аренды Steam-аккаунтов CS2 на Playerok + Telegram-бот для управления.

## Запуск

```
pip install -r requirements.txt
copy .env.example .env   # заполнить BOT_TOKEN и ADMIN_IDS
python bot.py
```

## Как работает

1. В боте: «🆕 Новый товар» → логин → пароль → maFile → название → описание → цена → часы →
   Prime → картинки (до 5) → «Выставить обычным / с премиумом». Бот сам создаёт лот в категории
   аренды CS2 на Playerok и привязывает к нему аккаунт.
2. Покупатель оплачивает подходящий лот → ему в чат Playerok сразу уходят логин/пароль,
   сделка подтверждается, админу приходит уведомление.
3. В чате покупатель пишет `!код` — получает актуальный Steam Guard, `!время` — остаток аренды.
4. За `WARN_BEFORE_MINUTES` до конца — предупреждение; по окончании — сообщение покупателю,
   пароль Steam меняется всегда, тот же лот выставляется снова с новым паролем в комментарии.
5. Если свободного аккаунта нет — сделка встаёт в очередь и выдаётся автоматически,
   как только аккаунт освободится. Возврат по сделке сразу прекращает аренду.

Длительность берётся из атрибутов лота, затем из названия («3 часа», «2 дня»),
затем из настройки аккаунта, затем `DEFAULT_RENTAL_HOURS`.

## Цена со скидкой

Лот выставляется по ближайшей большей цене из 499 / 999 / 2499, затем по ID лота цена
меняется на желаемую — на Playerok видна скидка. Если желаемая ≥ 2499, ставится она сама.

## Как покупка находит товар

При покупке Playerok создаёт копию лота с новым ID, но slug копии начинается с последнего
блока ID исходного лота (`a1b2c3d4e5f6-arenda-cs2-...`). По нему бот и находит товар. Если по сделке
сделан возврат, а аккаунт не выдавался, лот выставляется заново.

## Автовыполнение заказов

После оплаты лота бот выдаёт аккаунт и сразу отмечает заказ выполненным (`AUTO_CONFIRM_DEAL=1`),
даже если сообщение в чат не ушло — логин и пароль есть в комментарии лота. При ошибке —
до 3 повторов. Раз в `DEALS_POLL_SECONDS` бот сверяет оплаченные заказы через API, так что
заказ, оплаченный пока бот был выключен, тоже будет выдан и выполнен.

## Тестовый режим

`TEST_RENTAL_MINUTES=2` в `.env` — любая аренда длится 2 минуты с момента покупки
(предупреждение за минуту). Для работы поставьте `0`.

## После аренды

По окончании аренды (по времени, вручную или после возврата) по порядку:

1. Смена пароля Steam — всегда. Код в `steam_password.py` перенесён без изменений из SteamHub
   (вход с ожиданием токена, `jwt/finalizelogin`, мастер HelpChangePassword с подтверждением
   через `identity_secret`). Поэтому maFile без `identity_secret` не принимается.
2. Тот же лот выставляется снова: в комментарии новый пароль, плюс правки товара, сделанные
   во время аренды. ID лота и привязка не меняются. Если покупатель ждёт в очереди — аккаунт
   сразу уходит ему.
3. Если Playerok не даёт выставить проданный лот повторно — создаётся новый лот по данным
   товара, а старый отвязывается и удаляется.

Если пароль сменить не удалось — товар выключается и не выставляется, приходит уведомление
с кнопкой «🔁 Повторить смену пароля»; бот сам повторяет каждые `ROTATION_RETRY_MINUTES`.

В «⚙️ Выставление»: обычное или ⭐ премиум и что делать, если на премиум не хватает баланса.
В карточке товара кнопка 🎯 переопределяет режим для него, «📤 Выставить лот» — выставить вручную.

## Баланс и вывод

«💰 Баланс» — баланс (доступно / к выводу / заморожено / ожидает), рейтинг, отзывы, лоты,
продажи, статистика аренд. «💸 Вывести на TRX-кошелёк» — сумма → адрес TRC20 (запоминается)
→ подтверждение. Провайдер вывода задаётся в `WITHDRAW_PROVIDER` (по умолчанию `USDT`).

## Cookies и прокси Playerok

Задаются только в боте: «🍪 Cookies» или `/cookies`. Cookies — текстом или файлом: строка
заголовка `Cookie`, JSON-экспорт Cookie-Editor/EditThisCookie или только `token`. Бот сначала
проверяет вход и только потом сохраняет и применяет их — без перезапуска. Прокси —
`ip:port` или `user:pass@ip:port`, `-` — без прокси.

User-Agent бот генерирует сам при первом запуске (Chrome под Windows, той же версии, что и
заголовки sec-ch-ua библиотеки) и больше не меняет. Раз в 5 минут бот проверяет вход и пишет,
если cookies перестали работать.

## Редактирование товара

В карточке товара «✏️ Редактировать товар»: название, описание, цена, срок, Prime, картинки,
логин, пароль, maFile, привязка лота. Правки лота сразу применяются к выставленному лоту на
Playerok (может уйти на модерацию); если аккаунт в аренде — сохраняются и попадут в следующий
лот при перевыставлении. Картинки хранятся в `images/<id>/`.

Стандартное описание — `DEFAULT_ITEM_DESCRIPTION`, комментарий к лоту — `ITEM_COMMENT` в `config.py` (`{login}` и `{password}` подставляются). При запуске бот приводит комментарий всех выставленных лотов к этому шаблону, не удаляя их; при смене логина или пароля комментарий лота обновляется.

Команды бота: `/start`, `/accounts`, `/status`, `/balance`, `/cookies`, `/add` (новый товар).
